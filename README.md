# Análisis Bot Ventas

## Descripción del proyecto

Este proyecto realiza un análisis de información de ventas mediante un bot de ventas.

El análisis permite obtener información sobre:

* Ventas totales por categoría.
* Porcentaje de participación de cada vendedor.
* Productos con mayor frecuencia de venta.
* Distribución de las ventas según el método de pago.

El proyecto busca facilitar la interpretación de los datos de ventas y obtener información útil para la toma de decisiones del negocio.

## Instrucciones de instalación

Para ejecutar el proyecto se necesita tener instalado Python.

También se requiere la biblioteca Pandas para trabajar con los datos.

### Instalación de Pandas

En la terminal ejecuta:

```bash
pip install pandas
```

Una vez instalada la biblioteca, el proyecto estará listo para ejecutarse.

## Cómo ejecutar el proyecto

Para ejecutar el análisis de ventas, se debe abrir una terminal en la carpeta del proyecto y ejecutar el archivo principal:

```bash
python analisis_rama_36.py
```

El programa realiza el análisis de los datos de ventas y permite obtener información sobre las categorías, vendedores, productos y métodos de pago.
